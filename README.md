# 客户接待工作台

当前源码及最新公开发行均为**0.3.14**。本版恢复接待提示词的事实/意图、权限、否定更正、资料用途、续答及润色规则，并新增按客户会话保存的业务补充图片、PDF及文本附件。继续沿用中文需求、独立摘要、程序商品链接及参考图、产品/供应商与持久采购任务。下载和范围见[发行页](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.14)、[发布说明](docs/0.3.14发布说明.md)与[验证记录](docs/verification/0.3.14.json)。自动定向询价和报价回收仍未验收。

安装包、便携ZIP和更新附件已发布，最终EXE窗口及固定更新签名已核对；本次没有替换已安装程序或迁移真实数据。0.3.12及更早版本保留历史记录。工作台以Accio授权环境的自动客户接待为主，保留普通人工聊天、业务补充和主动建议；需求由Accio直接用中文整理，第三方通用文本模型只负责聊天及有效人工建议翻译，译文保存在本机。

0.3.9支持分层资料用途，内置六份接待规则与三份经营模板，全部默认关闭，由当前商家编辑采用并明确启用。自动、建议和润色共用资料及当前客户补充；公司名和通用二进制MIME图片读取已修复，并在授权环境只读复验通过。完整规则及各处提示词见[实施计划](docs/接待质量与资料政策优化开发计划.md)、[内置全文](docs/内置资料与政策内容草案.md)和[提示词审核稿](docs/接待提示词审核稿.md)。

0.3.10 默认检测2秒、连续消息合并1秒，文字上下文保留最近50条及必要旧依据；单个AI执行槽与业务协调分离，支持取消过期生成及优先处理已就绪发送。采购事项采用短品类，支持查看和复核候选、独立整理、协助及来源更正。双方图片不再固定限制四张，默认整批64 MiB、准备60秒、并行2项；普通润色不自动读取历史图。高级设置提供翻译、提问和品类必填模板，资料页可调整风格优先级。

0.3.13将客户需求与独立会话摘要分开。同商家不同客户的同ID询盘可复用商品档案，数量、规格、预算和补充仍各自独立。数字商品ID的链接由程序按 `https://www.alibaba.com/product-detail/_<ID>.html` 生成，不由AI查询或填写，也不作为指定上下文或语义指纹输入；原聊天和冻结润色正文中的链接保留。无平台ID的明确自定义需求使用稳定的`定制-数字`本地编号，偶然碰撞时原子换号，不生成平台链接或请求平台图片。

商品展示参考图与客户需求图片分开：后台从正式商品图片组读取并安全本地缓存，只用于展示及采购找货，不进入接待图片上下文、清单或指纹，也不替代客户图片。读取使用独立媒体池，不占AI槽；采购可等待图片终态后选择图或文字找货。[只读报告](artifacts/verification/reception-0.3.13/product-image-component-accio.json)记录了list-information的images组件：返回不含商品ID或主图标记，按确切请求绑定商品并取最小imageIndex作为展示参考，不代表平台已证主图或SKU图；样本商品1601902417143的在售状态未知。真实SKU和图搜尚未验收。

已核实当前workctl v0.1.65外部接口没有原生图片附件参数。双方原图按p1/p2与时间顺序关联，在同一业务任务中原生读取；每次独立请求，不建立长期客户记忆。正常自动发送沿用[通道简化](docs/自动发送通道简化.md)，保留完整本地业务检查、来源版本、防重、重试与unknown原操作核查。历史0.3.8候选及0.3.7公开交付记录分别保留在各版本说明中。

小版本只运行改动范围内的定向验证；本版未运行全量测试。第三方翻译继续沿用同一Windows用户共享地址、模型和加密Key，各商家分别启用。公开交付不代表本机安装已替换、业务数据已迁移或所有真实业务场景已经验收。

这是位于`E:\ReceptionWorkbench`的独立源码项目，源码保存在私有仓库[juccistar/reception-workbench](https://github.com/juccistar/reception-workbench)，默认分支为`main`。本目录使用自己的`.git`，后续开发、提交和推送均在该独立仓库进行。原仓库和临时导出分支仅保留为来源历史，见[项目与仓库约定](docs/PROJECT.md)。安装包发布和客户端更新继续使用原公开发行仓库[juccistar/reception-workbench-releases](https://github.com/juccistar/reception-workbench-releases)。

初次复制只纳入247个必要文件，未复制旧Git对象、发行包、历史截图、旧依赖目录或业务数据。初次导出时237个非文档文件与原检查点逐字节一致；当时的独立项目调整仅涉及仓库元数据、打包入口和文档，0.3.4功能变更另见本版说明。原始来源与验收记录保留在[来源清单](docs/SOURCE_BASELINE.json)，当前仓库关系见[项目约定](docs/PROJECT.md)。依赖在本目录重新安装；新环境108项后端定向检查、87项工具测试、类型检查、构建和实际Demo窗口均通过，见[验证记录](docs/verification/0.3.3.json)。未运行完整测试套件，真实平台两轮发送与原14字符Ready展示仍待验证。
