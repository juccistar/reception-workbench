# 其余页面设计计划

面向接待人员、负责报价与找货的业务人员，以及产品评审。延续接待页已采用的雾白、钴蓝、墨蓝、松绿与琥珀五组角色色，以及纯白内容表面；Segoe UI 与微软雅黑 UI 分别承担拉丁文字和中文。主标题 24 px、页面正文 14 px、表格和辅助正文 12–13 px。文本左对齐，金额与数量按列对齐。

入口为 pages.html，使用本地 hash 路由组织。接待页保持独立，通过导航与新页面相互连接。所有状态、客户、账号、价格和记录均为合成数据。

## 页面与结构

| 页面 | 内容结构 | 主操作 |
| --- | --- | --- |
| 开始 | 待处理事项为主栏，接待状态为辅栏，近期客户与资料在下方 | 继续接待、处理报价 |
| 产品库 | 与采购中心一致的紧凑清单，每行仅用小缩略图，列出规格、方案、客户与更新 | 查看供货方案、设为默认方案 |
| 供应商 | 可筛选供应商清单，详情列出商品及进价 | 查看商品、查看供货方案 |
| 采购中心 | 按任务状态筛选的找货列表，详情展开来源与结果 | 查看结果、核查原任务 |
| 待我报价 | 左侧采购事项与右侧详情各自滚动，支持同客户多事项 | 保存会话补充、回到客户 |
| 客户资料 | 客户清单和会话摘要，详情包含历次需求 | 打开聊天 |
| 资料与政策 | 分类、文档清单、编辑区组成三栏 | 新建、保存、明确启用 |
| 接待与其他设置 | 分类导航加分组表单，保存区域固定 | 保存设置、按范围开启接待 |
| 运行记录 | 按时间排列的连接、资料与业务任务，按需展开诊断 | 查看任务、核查找货结果 |
| 启动台 | 全部 / 国际站 / WhatsApp 并列账号卡片 | 连接、打开窗口、编辑 |
| 共享模型 | API 列表及接待 / 翻译路由 | 添加 API、保存分配 |
| WhatsApp 客户侧栏 | 原始聊天位置示意与可收起的客户资料 | 关联客户、人工接管 |

## 自检后确定的取舍

不把所有页面都改成相同的统计卡片：产品用商品目录，供应商用清单，资料用编辑区，运行记录用时间列表。开始页优先呈现可继续处理的业务，而不增加无法证明的业绩统计。详情和维护参数放抽屉或折叠区，保留短动作中文。

定向询价与报价回收继续显示尚未开放，不出现可执行的批量询价按钮。找货结果未知时只核查原任务；账号连接和自动接待分开。新增资料默认关闭，人工备注不能进入 AI 上下文；共享模型 Key 不回显。备份恢复只演示完整集合及空目标边界，不触碰真实文件。

## 2026-11-16 用户追加要求

取消发送记录功能：不保留发送记录弹窗、按钮或其他页面中的替代入口。聊天原文仍正常展示，当前发送进度、失败和待核查提示直接在聊天中呈现；底层防重账本与原操作核查数据继续保全。运行记录仅展示连接、资料及业务任务。

客户不显示头像：实际接口无法采集头像，客户列表、聊天顶部、客户档案和关联选择均采用姓名与状态排版，不放照片、绘制人物或字母头像占位。

## 预览与交付

页面间导航、搜索筛选、详情抽屉、表单保存、新建资料、模型及账号设置均提供本地交互。接待页另有历史补全、资料与补充拖动、23 个状态及弹窗场景。新增的自动接待范围下拉框只在设置里控制自动接待覆盖范围；当前客户仍通过左侧列表切换。宽屏、窄窗口与异常场景使用独立 Electron 窗口验证，实际结果分别保存在 suite-verification.json、preview-verification.json 与 feedback-verification.json。此次交付为设计稿，不改生产页面或构建正式版本。
