# 本轮设计修订要求

面向产品评审与后续实施。以下为 2026-11-16 用户在本轮设计过程中的追加要求，以后追加的更具体要求为准；此目录交付设计原型，不表示生产功能已经同步修改。

1. 继续完成接待页以外的各页面，并串联导航。
2. 取消发送记录功能及所有入口。当前发送进度、失败和待核查提示留在聊天中；防重账本及原操作核查数据保全。
3. 实际接口采集不到客户头像，客户列表、聊天顶部、档案、关联选择不显示头像或字母头像占位。
4. 产品库采用与采购中心一致的紧凑清单，每行小缩略图，不用大图卡片。
5. 所有页面采用同一份主导航；进入接待、聚焦聊天、收起资料不能改变导航的图标、顺序、尺寸或位置。
6. 接待页提供各种弹出、进度和提示的具体方案，按需使用确认弹窗、就地提示、顶部提示、短暂轻提示。
7. 聊天顶部常显“补全历史”，只读补全当前客户历史，不触发自动回复或新建事项。
8. 右侧资料栏宽度可横向拖动；采购需求与业务补充之间可上下拖动调整高度。
9. 自动接待简单一键启停，按设置中已选范围处理客户，并排除人工接待客户。按最新要求，启动与生成建议都不做 AI 预检，直接执行；只有实际调用失败后才弹出“AI 不可用”提醒，保留当前正文和业务补充，仍可重试及人工发送。平台连接页的模型检查独立，不作为启停或建议的前置条件。
10. 此要求针对本轮新增的自动接待下拉控件，明确标为“自动接待范围”，不据此改造原有当前客户选择或生产接待对象设置。该控件只在设置页提供“全部客户”“选中客户”；后者立即在下方展开可搜索、多选的客户名单。顶部仅呈现接待状态及“开启自动接待 / 关闭自动接待”按钮。
11. 待我报价的事项列表与详情分别在可用高度内滚动；大量事项不无限撑高页面，切换事项保留列表位置，并用多事项样例验证。
12. 回复建议与润色结果都显示外语正文和中文译文，采用结果时只替换外语正文。
13. 取消人工接管、恢复自动接待及发送相关的额外确认弹窗和手动核查入口。未确认发送只呈现状态，底层未决记录与防重仍保全。
14. 译文、图片、历史补全等提示只保留必要状态，不加“原文不受影响”“需求内容不受影响”“不会触发回复”等解释。
15. 点击需求来源直接定位对应消息，不增加来源依据弹窗。
16. 自动接待按设置中实际选中的范围生效，不在启动提示里硬写接待全部客户。设计稿在同一预览标签页内保留范围，换页及重读设置时沿用选择。
17. 新版为 0.4.2。聊天消息标题继续使用原来的完整时间格式 YYYY-MM-DD HH:mm:ss（含秒）；客户列表的布局、筛选、预览、状态及紧凑时间呈现按设计稿实施。

合成数据、账号、Key 占位、模型检查与平台动作都只用于本地设计预览；不读取真实业务数据，不连接模型或平台，不执行真实发送、授权或迁移。
