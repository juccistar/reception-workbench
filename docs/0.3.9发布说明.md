# 0.3.9 资料政策与接待质量

0.3.9 已于 2026-11-12 完成打包、核验并在[原发行仓库公开发布](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.9)，已设为最新版。四个公开附件的服务端摘要和匿名完整下载均已核对；实际证据统一记录于[本版验证](verification/0.3.9.json)。

## 本版内容

- 修复公司名称读取：支持平台实际返回的 skill.accio.com 资料域名，保留受控下载、身份及字段校验。
- 修复原图读取：已核实来源返回 application/octet-stream 时，识别并完整解码实际 PNG/JPEG/WebP，不因通用 MIME 误拒绝合法图片。真实失败样本已读回并解码通过。
- 资料与政策支持类别、启用状态、仅人工查看、AI 内部接待依据及可用于客户回复三种用途。内部正文与公开口径分开，旧非公开资料不自动进入 AI。
- 内置六份可编辑接待规则和三份待填写模板，全部默认关闭；查看、编辑并主动采用后才影响当前商家。关闭保留正文，更新不覆盖用户修改或自动重新启用。
- 自动、建议、润色共用适用资料和上下文；补充仍只保存当前正文。额外有界补入相关本地历史原文，卡片信息不自动解释成寄样、报价接受或执行同意。
- 共用提示词区分客户需求、商家能力、双方同意及实际进度。聊天风格由明确启用的资料提供；润色保持原意及商务条件，质量提醒独立展示。
- 自动生成可返回结构化协助请求；人工建议只显示协助建议。业务员明确点击开始后显示处理中，待办不冒充团队已经行动。核实结果与通知回执仍分别记录。
- 运行记录增加读取失败阶段与固定类别，不记录原始响应、签名 URL 或凭据。
- 翻译保持独立，提示词版本更新后保留可读取的旧版第三方缓存，不自动批量重译。

## 图片输入核实

已核实当前 workctl v0.1.65 的 desktop query、desktop bridge 帮助及正式 schema：受支持的外部入口未提供原生图片附件提交参数。界面能上传图片与外部程序能够上传图片是不同能力，不能将文本中的路径、URL 或自造参数当作已提交图片。

本版实现 p1/p2 等本轮图片短编号及按时间排列的聊天投影，保留消息与买卖双方身份；实际原图继续通过同一主业务请求中的原生 read 读取。不先做独立图片识别任务，不增加发送前平台历史重读或 AI 复核。每轮买卖双方合计最多四张，原始消息正文不改写。

## 使用

进入“资料与政策 → 内置内容”，查看全文，选择“编辑并采用”。核对正文、用途及适用范围，明确勾选启用并保存。产品和经营条件模板需填入核实后的实际内容；未填写的占位内容不能成为客户事实。

“我的资料”中可以关闭或修改采用项。资料按商家隔离，不跟随共享翻译连接跨商家同步。资料开关不代表已经开启自动接待；重启仍保持接待暂停。

客户页可查看建议质量提醒、尚未创建任务的协助建议，以及公开事实与内部规则的应用版本。“开始处理”仅记录业务员已经开始核实，不会发客户消息或自动恢复接待授权。

## 验证及交付边界

按改动范围执行 231 项后端、80 项桌面/宿主定向测试，类型检查和最终构建通过，没有运行全量测试。源码及包内资料页验证默认关闭、启用/关闭后的上下文变化、正文保留和重启状态；包内双方图片预览、角色上下文、翻译配置与缓存重开检查通过，十张包内窗口截图已实际查看，测试窗口正常关闭。便携及安装运行目录均与冻结源码、内置资料资源及构建输入匹配，完整发行清单和签名核验通过。

公司名及已定位的同一张商家图片在授权环境只读复验通过。合成文本模型累计启动七次，包含保留的首轮 facts 结构失败；明确类型后自动输出复验通过，最终人工建议/润色的结构化提醒与商务条件保留检查通过。个别建议仍有一般化的费用表述和过强的后续预期，需要业务员审阅后采用；小样本不能代替全部真实接待验收，具体结果与边界见验证记录。

正常自动发送继续使用直接提交、来源版本、防重、最多三次明确未提交的暂时失败重试，以及 unknown 原操作核查。升级不补发历史失败或恢复自动授权。

本轮不替换本机安装、不迁移业务数据、不关闭商家窗口、不执行真实客户发送或飞书业务登记。安装前保存编辑、正常退出并按现有流程保留完整备份，再从对应商家的 Accio 授权环境启动。
