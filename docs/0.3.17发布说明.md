# 0.3.17 商品图与复制修复、WhatsApp原生接入

日期：2026-11-13。供接待人员、维护及验收人员阅读。

状态：分阶段开发中。先完成商品图、文字复制和完整消息时间修复并提交，再开发WhatsApp；全部完成后才打包上传。当前公开最新仍为0.3.16。[开发方案](0.3.17开发方案.md)与[验证记录](verification/0.3.17.json)记录执行进度。

## 第一阶段修复

产品ID和链接复制改为受限宿主入口：后台核对字段及商家归属，主进程调用异步剪贴板写入并等待完成，再反馈成功，修复浏览器写权限被统一拒绝的问题。接待页和产品库均使用同一能力，提示贴近相应字段；切换客户/事项不显示迟到反馈。启动指令复制也等待系统写入完成。

商品图新增读取/重新采集。手动重采受理后清除当前商品旧图引用并递增版本，新图整组覆盖，失败不回退；部分成功只显示本轮有效图片。重复点击合并活动任务，旧loading/unknown/failed可明确请求恢复；状态区分平台无图、结构错误、下载失败及部分失败。无其他引用的旧展示资产按候选清理，消息、补充和其他有效资产不误删。需求关联缺失可本地补齐，不通过AI重写需求或重复采购。

国际站每条消息上方直接显示“姓名 YYYY-MM-DD HH:mm:ss”，使用本地时区、24小时制和完整秒数，不增加日期分隔；缺失或无效时间显示时间未知。

## 后续WhatsApp范围

左侧独立模块使用WhatsApp Web原始界面，自动接待覆盖全部单聊，包括未绑定国际站及后续新联系人。国际站绑定仅作为可选背景增强；国际站聊天、只读需求和补充进入对应WhatsApp的AI上下文，WhatsApp不反向写回国际站消息、摘要、需求或采购/登记。

该模块的同页面适配、实际连接及自动收发尚待后续阶段实施和验证。旧自绘原型不是本版实现或验收证据。

## 验证边界

第一阶段相关后端、宿主与renderer定向用例及类型检查已通过；修复源码构建及实际窗口结果以验证记录为准，未运行全量测试。隔离窗口使用合成资料；系统剪贴板验收只读回本次测试刚写入的合成ID、链接和图片，不读取既有剪贴板内容。真实平台商品读取、WhatsApp登录/收发、安装和业务数据迁移各自按明确对象与授权核验，不由合成回归推断通过。
