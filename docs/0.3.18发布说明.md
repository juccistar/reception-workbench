# 0.3.18版本说明

日期：2026-11-14。面向工作台使用者与维护人员。

状态：开发验证中，公开发行仍为0.3.17。构建、窗口验证及交付状态以[验证记录](verification/0.3.18.json)为准。

## WhatsApp连接与界面

继续在左侧WhatsApp模块使用原始网页，不另外启动Chrome，不迁移现有商家的登录目录。

修复中文应用名进入请求头后导致登录页HTTP 400的问题。中文窗口名称保留，WhatsApp专用页面与会话请求采用规范的产品标识，浏览器版本取实际运行环境。

连接会分别处理网页失败、网络/TLS错误、模块准备超时、SDK引导超时及认证后聊天加载超时。错误页停止初始化，重连前释放旧监听与连接；扫码等待单独显示，普通断开保留登录资料。内嵌页保持后台运行，切换工作台模块不应冻结脚本等待。

内部浏览器协议报告实际内核版本，SDK继续操作同一个可见页面。全部入站单聊接待与国际站可选只读背景沿用现有规则。

## 后台执行保护

后台调度、任务分派及收尾增加异常保护。可隔离的故障继续由原线程处理后续工作；连续调度故障有限退避后明确停止，不创建第二个消费者。

独立健康检查和事件可在完整工作区查询等待时报告执行异常。确认异常后，国际站与WhatsApp自动发送授权撤销，界面不再继续显示正常接待；恢复和重启不会自行重新授权。

每次出队单独记录完成归属，避免异常清理重复结算。发送状态不明时保留原操作和unknown；已受理证据不因收尾异常被改写。原人工发送请求仍可查询既有任务编号。

正常空闲、图片准备及AI等待分别按对应阶段预算判断。诊断仅记录异常类型、阶段和受限堆栈位置，并轮转限量保存；聊天正文、凭据及原始异常全文不进入这些日志。

## 聊天展示精简

删除“本次图片覆盖：0/1张原图已准备”及其展开说明，保留摘要、原图、右键复制和业务补充。后台图片准备、AI实际读取证据与发送检查继续执行。

## 验证范围

按改动范围执行定向测试与类型检查，不运行全量测试。实际窗口使用临时Demo资料，健康异常展示通过受限宿主事件注入验证，真实线程故障、撤权和队列收尾由独立Python定向用例验证。

公共网页检查只证明页面、环境和SDK引导的对应结果，不代表真实账号登录、客户收发或平台受理通过。未执行实号测试、真实数据迁移、安装、公开发布或私有源码推送。
