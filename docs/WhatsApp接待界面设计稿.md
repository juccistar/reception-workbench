# WhatsApp界面约定：独立模块与原始Web界面

日期：2026-11-13。面向接待人员、开发及验收人员。

状态：按用户最新要求修订，已并入[0.3.17开发方案](0.3.17开发方案.md)。采用WhatsApp Web原始界面，不再采用此前自绘聊天UI；当前程序仍为0.3.16，原生页面和SDK同会话适配尚未实现或验收。

## 1. 入口与页面

左侧导航新增独立“WhatsApp”，与“客户接待”并列。国际站聊天继续在原客户接待模块；WhatsApp聊天不进入该列表，不添加“全部/国际站/WhatsApp”共用会话页签。

WhatsApp模块主体直接承载真实WhatsApp Web页面，使用其自身联系人列表、聊天气泡、搜索、附件及发送输入框。这里的原始界面指网页，不是把Windows版WhatsApp安装程序嵌进工作台。

外层仅保留本程序需要的控制：

- 当前商家、WhatsApp连接账号及接收状态。
- 明确的当前控制联系人，以及其国际站绑定状态。
- “绑定国际站对话/调整绑定”和“查看带入背景”。
- 该账号“全部单聊自动接待”开关、当前客户接管/暂停状态及未决自动发送提示。未绑定国际站不禁用自动接待，绑定入口只用于补充背景。

布局约定：

```text
工作台左侧导航                  WhatsApp独立模块
                              ┌───────────────────────────────────────┐
客户接待                      │ 账号/当前联系人 · 国际站绑定 · 自动接待 │
WhatsApp  ← 新入口            ├───────────────────────────────────────┤
产品库                        │                                       │
供应商                        │       WhatsApp Web原始界面            │
……                            │  原有联系人列表、聊天与输入框均保留   │
                              │                                       │
                              └───────────────────────────────────────┘
```

这是容器和外层控制位置说明，不重新设计或仿制WhatsApp聊天内容。

## 2. 绑定及背景详情

从外层打开小弹窗：显示确切WhatsApp账号/联系人，搜索同商家国际站会话，核对客户名及关键原文后确认绑定。若无法从原始页面可靠取得当前chat_id，则在弹窗明确选中后台核实的联系人，不用姓名猜测。

“查看带入背景”按需打开抽屉，展示绑定国际站会话、已同步截至时间、将使用的聊天/摘要、只读需求和业务补充。关闭后完整回到原始WhatsApp页面；不常驻另一份自绘需求/聊天侧栏。

登录、可选绑定与开启账号全部单聊自动接待分开。绑定变化只使旧背景版本和未提交AI结果失效，不把未绑定变成禁止接待条件；原本正在接待且仍有待回复消息时按新背景重新生成，原人工接管/暂停状态继续保留。当前可见聊天切换不能改变后台已冻结的发送目标。

## 3. 单向显示与状态

国际站背景供AI理解客户，不逐条发成WhatsApp气泡。WhatsApp原始消息、人工回复和自动回复只存在于WhatsApp及独立本地记录中，不回填国际站聊天、摘要或需求。

发送未知时外层提供核查入口，程序不再新增自动发送；用户仍能在原生UI或手机手工操作，不能将原生输入框说成已被程序锁住。检测到人工回复后接管该WhatsApp客户，并保留原unknown待核查。

WhatsApp账号、AI能力、接收就绪、全部单聊接待和ACK分别显示；重连不恢复自动授权。未绑定、已绑定及后续新单聊客户均纳入账号接待范围，单客户仍可人工接管/暂停；全部单聊不包含群聊/广播/状态/频道，也不批量主动补发历史联系人。未绑定时背景详情显示“未关联国际站，使用WhatsApp对话及商家通用资料”，而不是阻止自动接待。

## 4. 国际站消息时间

工作台自己的国际站消息头按用户要求直接显示：

```text
Kayla ca 2026-11-12 14:05:05
商家 2026-11-12 14:06:18
```

每条消息保留发送方和完整年月日时分秒，不增加日期分隔线，不依赖鼠标悬停。WhatsApp Web原始界面的时间由其自身呈现，本版不改写远端页面气泡或时间样式。
