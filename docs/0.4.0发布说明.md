# 0.4.0：统一启动台与第三方图文模型

日期：2026-11-15。候选A完成原定本地验收后，用户发现启动台未显示旧版已登记商家；已确认新旧登记读取衔接缺失，修复与回归正在进行，候选A保留为历史验收记录。当前公开发行仍为0.3.21，未创建0.4.0草稿、上传或发布，实际状态见[验证记录](verification/0.4.0.json)。

## 使用变化

本版使用变化：

- 普通双击进入极简启动台，正式版取消 Demo 模式。启动台集中展示已登记商家，包括同一Windows用户的有效旧版登记；保持打开时定时刷新，重新获得焦点时也刷新。提供授权指引、打开工作台和切回已有窗口的入口。
- 模型配置集中在启动台。本机同一 Windows 用户下的全部商家共用 API 列表及接待、翻译选择，不再重复填写各商家的模型连接。
- 接待 API 处理自动回复、人工建议、润色、需求整理和摘要，有相关图片时同轮提交文字与受控原图。翻译 API 可使用独立的纯文字模型。
- 模型变更按实际依赖影响运行任务。接待配置变化撤销相关商家的自动接待授权，翻译独立变化不暂停使用另一配置的接待；商家业务数据与外发范围仍分别保存。
- WhatsApp 图片消息进入来源受控的媒体准备流程，保留图片说明文字；媒体下载完成不会额外制造一轮新消息或重新计算重试预算。
- 启动终端默认输出精简状态。非必要模块按需加载，优化重复消息解析、图片分块准备和界面事件刷新。

## 授权和数据

商家索引不是授权。当前连接仍须核验商家身份和平台读取能力；自动接待与采购需在对应商家中明确开启。保存模型 Key 不会自动开启所有商家的接待。

Accio 完全退出或 Windows 重启后的授权环境复用尚未验证，不承诺永久授权或自动续期。旧 Demo 目录不自动删除或迁入真实工作区；原业务目录、发送操作、accepted/unknown、回执和备份继续保全。

普通人工发送继续独立于 AI 检查和采购需求完整度。模型生成完成、平台受理及客户已读分别处理；已受理内容不重发，未知提交结果沿原操作核查。
