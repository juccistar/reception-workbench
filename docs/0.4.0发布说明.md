# 0.4.0：统一启动台与第三方图文模型

日期：2026-11-15。源码与定向回归、正式启动台和隔离工作台窗口已通过；候选构建及公开发行状态以 [验证记录](verification/0.4.0.json) 为准。当前尚未公开发布 0.4.0。

## 使用变化

本版使用变化：

- 普通双击进入极简启动台，正式版取消 Demo 模式。启动台集中展示已登记商家，提供授权指引、打开工作台和切回已有窗口的入口。
- 模型配置集中在启动台。本机同一 Windows 用户下的全部商家共用 API 列表及接待、翻译选择，不再重复填写各商家的模型连接。
- 接待 API 处理自动回复、人工建议、润色、需求整理和摘要，有相关图片时同轮提交文字与受控原图。翻译 API 可使用独立的纯文字模型。
- 模型变更按实际依赖影响运行任务。接待配置变化撤销相关商家的自动接待授权，翻译独立变化不暂停使用另一配置的接待；商家业务数据与外发范围仍分别保存。
- WhatsApp 图片消息进入来源受控的媒体准备流程，保留图片说明文字；媒体下载完成不会额外制造一轮新消息或重新计算重试预算。
- 启动终端默认输出精简状态。非必要模块按需加载，优化重复消息解析、图片分块准备和界面事件刷新。

## 授权和数据

商家索引不是授权。当前连接仍须核验商家身份和平台读取能力；自动接待与采购需在对应商家中明确开启。保存模型 Key 不会自动开启所有商家的接待。

Accio 完全退出或 Windows 重启后的授权环境复用尚未验证，不承诺永久授权或自动续期。旧 Demo 目录不自动删除或迁入真实工作区；原业务目录、发送操作、accepted/unknown、回执和备份继续保全。

普通人工发送继续独立于 AI 检查和采购需求完整度。模型生成完成、平台受理及客户已读分别处理；已受理内容不重发，未知提交结果沿原操作核查。

## 验证和发行

后端40个文件428项、桌面/宿主18个文件92项及工具6项定向检查通过，类型和提示词一致性检查通过。两次源码构建均完成后立即本地提交，最新源码构建为97fe7c2；正式启动台和两组隔离交互共11张截图已逐张查看。窗口中发现的Windows盘符来源误拒已修复，失败记录保留。完整记录见[后台回归](verification/0.4.0-backend.json)和[窗口记录](verification/0.4.0-windows.json)。

合成消息查询测量中，5万条工作区最近50条查询中位数由3.75045 ms降为2.85445 ms，20万条由1.3448 ms降为0.92505 ms；240条小工作区略慢。测量仅覆盖该查询，不代表整应用、真实模型或网络延迟改善，范围见[性能记录](verification/0.4.0-performance.json)。候选闭包、实际EXE、更新签名和公开下载分别验收。

真实模型效果、实号登录收发和授权环境独立复用需要各自的实际验证；合成输入、替身协议测试及本地窗口截图不能替代这些结果。是否完成公开发布、是否安装到本机、是否迁移真实数据均单独记录。
