# 0.3.6 发布说明

本版修复切换商家或 Accio 多开环境后，聊天翻译 API 配置不能共用的问题。[0.3.6 已公开发布](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.6)，实际验证范围见[验证记录](verification/0.3.6.json)。

## 本版变化

- 同一电脑、同一 Windows 用户下，各真实商家窗口共用翻译服务地址、模型和 API Key。已打开的新版窗口会自动同步，修改模型或 Key 后无需逐个重填。
- 配置保存在真实 Windows KnownFolder 的共享目录，避免 Accio 多开重定向 LOCALAPPDATA 后各存一份。使用 Windows CurrentUser DPAPI 加密整个连接配置，避开 Electron 各窗口 userData 独立的 Chromium 加密密钥。
- 首次升级时，从第一个具有有效旧配置的商家窗口自动导入。旧 Key 须通过原数据根绑定校验；不会覆盖已存在的共享配置，也不会恢复用户已清除的共享 Key。
- 启用仍按商家及实际数据根分别确认。其他窗口发现服务地址改变，或恢复/迁移到新数据根时会关闭本商家翻译并等待确认；清除共享 Key 后各窗口停用远端翻译。更换模型或 Key 不改变 Accio 接待授权。
- 通过共享修订号阻止迟到表单覆盖其他窗口的新配置。冲突时保留输入，并重读最新设置供放弃修改后恢复。
- 聊天、采购事项、译文缓存、用量及 Accio 授权仍按商家隔离；清缓存只处理当前商家的译文。Demo 使用独立的演示配置。

## 升级和使用

先保存并正常退出当前各商家工作台，再更新到 0.3.6。所有需要共享配置的客户端均应使用本版。

1. 先从已配置翻译服务的商家 Accio 授权环境启动新版，让程序导入已有连接。也可在任一新版真实商家窗口重新填写服务地址、模型和 Key 并保存。
2. 从另一个商家的 Accio 授权环境启动新版，在“连接与设置 → 聊天翻译设置”确认服务地址、模型和 Key 状态已经同步。
3. 在该商家单独确认启用，再在聊天页勾选“自动中文翻译”。无需再次填写 Key。

更换或清除 Key 会影响本机其他真实商家。启用开关和当前商家用量分别保存。不同 Windows 用户或不同电脑仍须分别配置，不提供云同步或跨窗口统一账单/限流。

## 验证范围

14 项后端、61 项桌面/宿主定向测试、类型检查及构建通过。真实 Windows DPAPI 在不同重定向环境下的加解密测试通过。源码和最终 EXE 均以隔离 Demo 双窗口实际验证了旧 Electron 加密格式迁移、地址/模型/Key 同步、单窗口停用、并发冲突保留输入、共享 Key 清除、业务数据隔离及关闭重开；最终 EXE 的原有翻译缓存、回复建议、本机 HTTP 网关保存和重开检查也通过。截图已实际查看，发布附件结果见验证记录。

验证只使用合成数据、独立临时数据根及显式共享目录覆盖，不读取或更改真实商家配置，不调用真实付费模型、不发送真实客户消息。没有运行全量测试，没有替换本机安装或迁移真实业务数据。Demo 检查不替代真实双 Accio 接待验收。

共享配置不进入业务备份；业务备份保留本商家启用/服务镜像及译文，恢复到新数据根后重新确认启用。数据库物理 schema 沿用 v2，新增数据根绑定位于控制库 JSON 实体。更新元数据使用固定 Ed25519 发布签名，本版未进行 Windows Authenticode 代码签名。
