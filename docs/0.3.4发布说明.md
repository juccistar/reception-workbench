# 0.3.4 发布说明

[0.3.4已公开发布](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.4)，四个附件的GitHub服务端SHA-256及匿名完整下载均核对通过。发布不代表本机已安装；本次未替换已安装程序。详细证据见[验证记录](verification/0.3.4.json)。

## 本版变化

- 聊天中文翻译使用可配置的第三方通用文本模型，支持兼容 Chat Completions 和 JSON 输出的服务，用户自行填写 API 地址、模型及 Key。
- 仅处理当前可见买卖双方聊天文字，逐项最多附带两条轻量前文。没有术语表、OCR、附件内容翻译或需求区翻译。
- 译文按商家、原文/前文、端点、模型和提示词持久缓存，关闭重开后可复用。无 Key 时也能查看当前已有缓存；不默认按90天自动删除。
- 翻译配置、合成检查、用量统计和显式清缓存独立于 Accio 接待。Key 由 Windows 本机加密保存，不进入业务数据库、Snapshot 或业务备份。
- 需求采集与客户回复仍由原 Accio 方案处理，在同一次分析中直接生成中文 summary/display_value 和客户语言 reply；事实原文、证据及发送保护保留。
- 修复 Windows 文件 URL 盘符大小写导致合法页面被拒绝的问题；UI 测试入口统一盘符形式，避免 Vitest 重复运行时标识。

使用步骤见[用户指南](USER_GUIDE.md)。首次启用或更换服务端会确认客户文字外发；真实模式合成检查可能计费，且不使用客户消息。

## 数据与使用边界

业务数据库物理 schema 沿用原版本，新增翻译 JSON 实体。原消息、需求和发送证据不被译文覆盖。升级不恢复自动接待授权。

Key 保存在本机商家宿主状态中，绑定实际数据根；换机器或迁移/恢复到新根后重新配置。译文和非敏感配置随完整业务备份保留。工作区用量不是服务商账单，网络超时后重试可能重复计费。

跨窗口共享预算、单价/金额折算、可选文字脱敏和自动保留期清理暂未提供。Windows 安装包证书状态与 Ed25519 更新发布签名分别核验；不把候选构建当作已完成安装。
