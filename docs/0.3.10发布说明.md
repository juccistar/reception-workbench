# 0.3.10 响应速度与采购需求

0.3.10 已于 2026-11-12 完成打包、核验并在[原公开发行仓库正式发布](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.10)，已设为最新版。四个附件的服务端摘要和匿名完整下载均已核对，完整证据见[本版验证记录](verification/0.3.10.json)。本版改善消息同步与 AI 等待的调度，统一采购需求展示，并修复 Windows 图片路径导致的润色失败。

## 主要变化

- 新建或缺少配置时，新消息检测默认 2 秒、连续消息合并默认 1 秒；已有保存值继续保留，不增加响应预设。
- 每商家独立运行一个可取消的 AI 执行槽。等待 AI 时仍可同步正文和执行本地操作，受保护的人工发送、回执核查及已就绪自动发送优先；保留公平调度和有界队列。未提交的旧生成可取消，发送 operation 继续使用原有协议。
- 修复重复读取相同消息时，观察时间变化使正在生成的有效结果被误判过期的问题；实质来源、历史覆盖范围和游标变化仍参与复核。
- 最近文字取 50 条。关键原文已在窗口内时直接复用，只补窗口外缺少的必要依据；模型输入使用按任务选择的字段和单份时间线，本地完整验证上下文继续保留。
- 修复 Windows 图片清单的 JSON 路径转义校验，保留精确路径、哈希、角色和来源绑定。普通文字润色不再自动准备无关历史图片。
- 取消本轮固定四图和回执固定行数限制，按完整清单核验。默认整批原图 64 MiB、准备时限 60 秒、同时下载 2 项；单图格式、大小和尺寸限制继续保留。原图准备就绪与模型本轮已读分别显示。
- 事项标题使用独立短中文品类，例如帽子、手链、项链、连帽衫；完整产品原文和细节保留。同品类多事项以编号区分，选择仍绑定原事项编号。客户页、待报价和客户资料复用需求展示与来源入口。
- 需求保留冲突候选、原文片段和来源版本，支持人工复核、待客户确认、驳回及有依据的补录。原文更正会使同会话受影响事项的来源失效，并提示复核原报价记录。
- 新增独立“整理需求”：先生成候选，再明确应用，不发送客户消息、不替换聊天输入、不隐式接管。支持新建采购事项，以及整字段或单个候选归入同客户另一事项。
- 主聊天页接通协助处理表单。明确开始、保存核实结果、需求裁决及跟进发送各自独立，保存结果不会自动消除需求冲突。
- 高级处理参数可设置图片预算、下载并发、同来源生成失败上限、追问元数据限制及翻译并发与上下文预算；按品类配置待报价必备条件。风格资料可设优先级，仍只选一份适用风格。
- 任务增加排队、执行、图片准备和 AI 查询耗时等安全诊断。有效来源、质量提醒与协助内容使用整体资源预算，不再按 100/10/5 条静默切断。

## 使用

在客户聊天上方展开“整理与复核需求”，可以修改展示品类、查看候选并明确应用，或为冲突字段选择有效来源。右侧需求卡可展开详情与全部原文；查看历史事项不会替换未保存的聊天正文。

“连接与设置 → 本地连接参数 → 高级处理参数”集中保存容量设置和品类条件。保存这些业务参数沿用现有撤权规则，需要重新检查并明确授权自动接待。追问限制作用于指令及已记录的受理提问次数，不是正文问句的严格计数，也不新增硬性发送门槛。

普通润色仍保持未发送正文及商务条件，生成后由业务员审阅再采用。译文按商家保存，第三方翻译继续独立于 Accio 接待和需求采集。

## 验证和边界

本轮通过 347 项后端、117 项桌面/宿主定向测试，类型检查和构建通过，未运行全量测试。最终发行 EXE 的实际窗口验收覆盖协助开始/保存、需求整理/应用、单候选移项、字段复核、原文定位、同品类多事项、280 像素侧栏、窄窗抽屉、重开持久化、高级设置保存、双方图片和翻译缓存；13 张截图已实际查看，测试窗口正常关闭。安装与便携运行目录的冻结源码、资源、更新签名及完整清单均已核对。

在数字商家 2500002588987 的授权环境共启动 3 次合成 AI 查询：建立自有合成工作区、5 张买卖双方混合色卡的同任务读取、普通文字润色。5 张均通过本轮来源、角色和哈希绑定校验；普通润色读取图片数为 0，并保留 15 美元及运费不包含的原意。没有打开真实商家业务数据库或向客户发送消息。

5 图合成请求本次约 183 秒，普通文字润色约 17 秒；这些是少量样本，不是稳定分位耗时或加速比例。图片仍采用同任务 read_compat，未增加原生附件接口；取消本地四图限制不代表平台没有资源上限。8 张和 20 张已完成离线清单及回执检查，真实平台本轮只验收 5 张。单次原生来源读取阻塞时，图片准备时限要在其返回后检查，不能承诺取消立即终止远端生成或计费。

需求来源和卖方转述过滤使用保守规则，不能保证覆盖全部自然语言表达；图片线索保持未确认，AI 提取通过程序校验也不等于人工复核或商家接受。人工建议仍需审阅。并行 Accio AI、改动查询超时、阶段采集模板及人工选择历史图片的独立界面留待后续验证。

正常自动发送保留完整本地业务检查、整会话未决发送保护、最多三次明确未提交的暂时错误重试，以及 unknown 沿原 operation 核查。升级不恢复自动授权、不补发旧失败，不迁移商家数据。本轮不运行安装器或替换本机已安装程序。
