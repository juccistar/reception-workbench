# 0.4.2 发布说明

面向工作台使用者与维护人员。已按最终确认设计稿逐页、逐弹窗修正生产界面，并删除聊天翻译设置。0.4.2 候选 A 安装器与便携 ZIP 已构建，构建完成立即本地提交 `657d4ea`；包内容、固定更新签名、冻结后台和候选窗口检查已完成，公开发布仍受 GitHub CLI 未登录阻塞。正式 EXE 独立首页本次未能建立新窗口，不计为通过。窗口、安装包与公开状态分别见[候选记录](verification/0.4.2-candidate-A.json)、[验证记录](verification/0.4.2.json)和[设计对照](verification/0.4.2-design-fidelity.json)。

## 主要变化

- 按已确认设计统一主导航、客户接待和业务页面。客户列表使用紧凑布局、筛选、最近消息及状态，不显示头像；消息时间仍保留完整年月日时分秒。
- 接待资料栏可收起并左右调宽，需求与业务补充之间可上下拖动。点击来源直接定位原消息，补全历史、译文和图片只显示必要的简短状态。原图弹窗使用标题、预览和操作底栏，可直接复制完整图片；复制继续核对受控来源并使用原有 PNG 及资源限制。
- 自动接待范围在设置中选择“全部客户”或“选中客户”，选择后者就地搜索勾选。顶部只显示运行状态与开启/关闭按钮，直接开启，无启动 AI 预检或重复确认；全部客户覆盖后续客户，人工接待中的客户除外。
- 启动后可直接生成建议和润色，结果中文译文独立于聊天译文显示开关。实际模型执行失败才提示“AI不可用”，保留正文；取消、来源变化和旧客户迟到结果不误报。人工接管、恢复和普通发送直接执行。
- 取消发送记录及手动发送核查入口。聊天保留当前进度和待确认状态，后台沿原账号、原操作和确切消息 ID 核对；历史批次、账本、accepted、unknown 及防重继续保全。
- 待我报价的事项与详情独立滚动，接待和报价共用同客户业务补充，切换前保存。响应丢失可核对原请求，真正版本冲突保留本地输入，处理差异后再应用。
- 产品、供应商和采购采用紧凑清单及按需详情；产品使用已有缓存小图。资料与政策按分类、文档和编辑区排列，设置分七类，移除聊天翻译子页与额外启用；接待页译文按钮直接使用统一翻译模型，历史原文与译文保留，维护诊断收起。运行记录只展示连接、资料和采购等任务。
- 图片单件上限调整为 20 MiB，既有业务补充最多 10 项、合计 64 MiB；支持静态 GIF，准备时限及原图批次预算按配置生效。资源按实际输入和处理阶段预留，保留来源、解码、完整性和模型预算约束，不以缩图替代原图。
- WhatsApp 保留真实 Google Chrome、多账号独立运行和原生客户侧栏。侧栏可保存当前单聊的文本补充，按账号、连接和商家分段校验；过期排队请求不能写入新视图。
- 修复历史补全与实时活动交错时的来源和买家状态，避免旧历史触发补答，同时保留确证的新买家活动。修复第一条受理后的自身回显、原 unknown 回执和缺平台时间戳造成的后续分条误停；只有确切受理证据才推进，不按同文重发。
- 修复带图生成时原文与图片标记混在一起、需求图片标识未提供的输入契约问题，自动回复和人工建议共用修复；无效来源继续拒绝，失败可定位到具体需求字段。历史三次失败的原始输出缺失，尚不能确认具体拒绝字段。
- 减少快照和待回复投影的重复消息解码，自动来源使用精确查询；附件展示缓存仍与模型权威原件校验分开。模型取消先撤结果资格，真实任务、输入和共享预算清理结束后才释放，迟到完成可收敛生成状态。

## 使用与数据边界

没有新增聊天附件发送、文件下载或中转接口。既有业务补充继续支持选择、粘贴和拖入，容量按本版图片边界调整，PDF 页数及文字提取上限保留；真实平台消息及回执以实际接口为准。没有开放定向询价、报价回收、群发或 WhatsApp 反写国际站。

保存范围或接待配置会撤权，重启不恢复接待。旧 incoming 范围转换为全部客户后仍须明确开启。消息、图片、原账本、回执和 unknown 不在升级时删除或补发。

现有数据库打开时不自动建立新消息索引，保持原 schema；新建的带索引工作区不保证由 0.4.1 的严格 schema 校验接受。回退须使用兼容的完整备份，不能手工删索引、回执或关闭标记。

本轮只运行改动相关的定向测试，没有运行全量测试。性能为临时数据上的局部测量，见[查询测量](verification/0.4.2-performance.json)和[集成测量](verification/0.4.2-integration-performance.json)，不代表整机、真实平台或模型提速。

设计修正后的源码与候选工作台均完成 24 项流程检查。源码 source-008 的 49 图、重建修正图及候选 A 的全部 49 图已实际查看，覆盖各业务页、七类设置、原图、客户历史、确认与退出弹窗及窄窗口；候选真实 Chrome 双账号与原生侧栏的 14 图也已逐张查看。共享模型页及其弹窗另有 9 图已查看，没有发起模型检查。早期 5c97dcc 和 36 图记录仍只作为历史阶段证据。

候选 179 个发行文件、180 个 ZIP 条目、118 个 Python 输入、3377 个 SDK 文件、5 个扩展资源、安装与便携版的 99 个共同资源及固定 Ed25519 更新签名均已核对。冻结后台完成两种模型协议的 18 次本地替身请求、14 个图片附件，原 unknown 的完整备份恢复、大于旧上限的 PNG 和静态/动画 GIF 检查通过。图片冻结探针不覆盖原图私有回读、精确 20 MiB 边界或全部 JPEG/WebP 情况；安装器没有 Windows 代码签名。

正式 EXE 独立入口检查在创建新窗口前以 0 退出；本机现有安装进程仍在运行，具体阻塞原因尚未确定，没有终止现有会话。商家路由及旧登记哈希、模型文件元数据前后不变，驱动没有打开模型页。实际安装、真实账号收发、真实模型效果及历史三次失败的原输出重放均未执行，合成窗口和冻结后台不能替代这些验收。
