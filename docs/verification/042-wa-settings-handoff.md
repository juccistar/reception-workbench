# WhatsApp 商家设置接线

商家只读上下文现包含 `reception_images_enabled` 和 `context_message_count`，并参与上下文 revision。独立账号根据该租约选择消息窗口与图片，发送前原有上下文 revision 校验仍生效。

仍需主线程完成：商家 `service.py` 保存上述设置时，经已认证的宿主/商家 broker 向关联的独立账号进程发出来源变化通知；账号在锁内取消该商家的在途生成及尚未提交的准备操作，并保留 unknown、原 operation、实际线程退出前的预算。应校验商家身份、实例与代次，避免通知其他商家；还须覆盖模型运行中设置变化、迟到结果和发送前变化的合成回归。当前没有此主动通知，因此正在运行的旧模型调用不会立即取消；现有发送前重新读取租约可阻止旧 revision 的准备操作发送。

账号和侧栏的全部设计状态尚未逐项对照或进行窗口验收。
