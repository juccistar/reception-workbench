# 0.3.13开发说明

日期：2026-11-13。当前源码及最新公开发行均为0.3.13，已打包并发布，见[发布说明](0.3.13发布说明.md)与[发行页](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.13)。本轮完成中文需求、独立摘要、接待布局、产品/供应商及持久采购任务，并整合程序商品链接、本地定制编号和独立商品参考图。**自动定向供应商询价及报价回收仍受阻，尚未完成真实验收。** 最终EXE窗口、固定更新签名及四附件匿名完整下载已核对；未执行真实安装、默认入口晋级、源码提交或真实商家数据迁移。

## 接待页面与需求

左侧导航及客户列表，中间为宽聊天区，客户标题下显示独立会话摘要，底部固定编辑器；右侧为需求和独立业务补充。窄窗使用需求/补充抽屉，支持键盘、Esc和关闭后焦点返回，已检查无横向溢出。

需求固定13项：产品、产品ID、产品链接、产品图片、数量与单位、关键规格、定制要求、收货地、客户期望交期、客户预算、包装要求、认证要求、联系方式。除程序派生的商品链接外，业务内容由AI依据对话直接用中文归纳，无依据留空；原文单独作证据，不再重复显示facts、requirement_items、display_value和商品大卡。

摘要绑定商家和会话，同一客户多需求共用，无需求也支持摘要、人工聊天和业务补充。正常接待与人工建议同轮更新，润色只改冻结正文，不修改需求或摘要。无需求保持真正的null，不再由空ID占位对象触发归属故障；真实错属case仍拒绝。

旧质量、待核实及待协助提醒退出生成、DTO、RPC和日常UI；需核实内容进入摘要。连接失败、真实任务失败、人工接管、未读、accepted/unknown发送回执继续保留。移除提醒没有放松发送依据检查，也没有将原语义提醒升级为硬性发送错误。

## 程序商品链接、本地编号及独立主图

数字平台商品ID由程序生成 `https://www.alibaba.com/product-detail/_<ID>.html`。AI与找货结果提供的原商品URL均不采纳；链接在需求区可选择、复制，但不进入接待指定上下文或语义指纹。该规则不证明页面存在、商品在售或页面内容可信。原始聊天、原文依据和冻结润色正文里已有的链接保持原样。

自定义产品允许“定制-6262662”形式的本地编号，须有客户需求依据，同事项稳定复用。无明确复用依据的不同需求偶然重号时，程序在事务内分配另一编号，避免误合并客户。本地编号不拼国际站链接，也不调用平台图片查询。

新增独立商品主图展示，保存于product_main_image和受限image_asset缓存，与客户需求product_images分开。主图不创建message_image关联，不进入接待photo_context、image_manifest或模型指定字段；补图不增加事项业务revision，不使有效建议过期。renderer只取本地安全PNG/JPEG data_url，不直接加载远程图片地址。

正式图片入口为 `icbu.product.list-information`，通过官方JSON参数文件传入：

```json
{"productId":1601902417143,"queryType":"trunk","componentList":["images"]}
```

只解析实测结构：外层data是JSON字符串，再解析到basicInfo.images[]，每项为imageIndex和originalImageUrl。程序选择最小imageIndex对应图作展示/找货参考，保留selection_rule=lowest_image_index、primary_verified=false，页面注明“平台图组首图，仅供展示和找货参考”。未知或歧义结构不猜字段，不回退其他查询。

该接口没有回传商品ID，因此归属依据是已核商家身份及确切单次请求参数，不能称“响应商品ID回验成功”；若出现显式异ID则拒绝。没有主图标志或首图即平台封面的已核说明，不能称已核实平台主图，也不是SKU图。

本轮按用户明确授权，从本店目录取得商品1601902417143并读取图片组件，返回6张图片；在售状态仍未知。随后用受限、无凭据下载器下载1张公开参考图，完整解码得到1000×1000的WebP，190830字节，生成188312字节的本地JPEG预览，已实际查看。只读查询及下载证据见[组件报告](../artifacts/verification/reception-0.3.13/product-image-component-accio.json)和[下载记录](../artifacts/verification/reception-0.3.13/product-image-download.json)。早期search/list-id空图记录保留，不能据此判断平台没有图片能力。

主图元数据及下载在有界媒体池执行，不占接待AI槽，不作为回复前置；采购可以等待其终态，再带冻结的确切公共图URL或仅以文字找货。真实图片下载成功不代表真实图搜已验收。

## 产品、供应商和采购

- 有效AI产品ID按商家+平台+ID原子建产品、需求关联和一次持久采购任务，不要求先人工建产品；队列满仍保留已接受的需求和待调度工作。
- 产品库、供应商和采购中心为独立页面，支持供应商新增/编辑、多个供货方案、默认方案及当前需求选择；同一供应商可供多个产品。
- 当前需求选择独立于产品默认，改默认不改变已有选择。选择及供货方案版本进入自动/人工生成指纹，依据变化使旧未发送结果失效；手写正文与已发送记录保留。
- 页面参考价不是供应商确认报价；进价不是对客销售价。禁用、过期或MOQ不适用的方案不能支撑回复。
- 同ID跨客户复用公共产品和采购任务，不共享数量、地址、预算、联系方式、聊天、业务补充或私发图片。
- 采购grant独立于接待，保存采购设置撤权，重启不恢复；默认最多3家候选，可配置1至3家。

找货使用同一Accio desktop query入口，提交前持久确定会话名、完整请求及指纹、agent和任务ID，调用前复核商家及采购授权。CLI失败/超时不视为未执行；仅恢复唯一匹配的原会话、请求、工具结果及终态答复。空链接、新客户、新job、暂停或重启不重新搜索，unknown只核查原任务。采购AI共用本商家执行槽，已生成回复不等找货完成，后续模型请求仍可能排队。

定向询价虽已有工具/schema资料，但本卖家资格、channel差异、回复域、受控提交及未知请求恢复尚未实测，工具也无已验证的远端幂等键。当前inquiry_available=false，阶段明确blocked，不会联系供应商或自动回收报价。图搜、全量SKU采集、自动销售价核算、下单和付款未验收。执行后的工具记录检查不构成提交前沙箱，宿主拒绝时不能换身份绕过。

## 旧数据与保全

Repository仍为schema v2，原生Ledger为v1。新需求不无条件采用旧facts或旧中文展示值，不在启动时全量调用AI改写历史。

离线prepare仅对正常关闭且checkpoint可核验的工作区执行：先制作并验证完整备份，再独占逐文件核对源hash，按reminder_cleanup.py白名单清理旧提醒entities/revisions、嵌入字段和独立标题。备份失败、占用或源变化均拒绝删除，无旧字段时不重复清理，历史备份原样保留。

原始消息、图片、job、draft、operation、outbox、intent、原生账本/回执及有效WAL全部保全；续答稳定来源/问题ID、结果版本、原操作关联及三次失败预算保留。清理只在临时合成工作区验证，本轮未打开真实商家业务库做回归，也未迁移或清理真实数据。
