# 0.3.13 接待页重构、产品库与供应商管理

日期：2026-11-13。供接待业务员、维护和验收人员阅读。本版已作为latest正式版公开发布，见[发行页](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.13)和[验证记录](verification/0.3.13.json)。发布时间为2026-11-13T03:12:42Z，发行编号443768284。实际安装版本仍以程序窗口为准。

## 接待页面与需求

接待页采用宽聊天区，客户标题下显示独立会话摘要，底部为回复编辑器，右侧是需求与业务补充；窄窗口支持键盘操作的抽屉。摘要按商家及会话保存，多项需求共用，无采购需求也能正常聊天、保存补充和生成建议。

AI直接用中文整理有依据的需求，原文另作证据，不再增加独立中文展示值。移除旧质量、待核实及待协助提醒，需核实内容进入摘要；真实连接、任务、接管、未读及发送回执仍独立保存。正文润色只修改冻结回复，不改需求或摘要。

数字商品ID由程序生成 `https://www.alibaba.com/product-detail/_<ID>.html`，不让AI查询或填写，可选择及复制。自定义产品可用稳定的“定制-数字”本地编号，不拼国际站链接或读取平台图；无关需求偶然重号时原子分配不同编号。

独立商品参考图通过list-information的trunk/images组件后台读取并安全缓存，只用于展示和找货，不替代客户图片，不进入接待指定上下文、图片清单或语义指纹。当前取最小imageIndex对应的图作展示参考，平台没有回传商品ID或主图标志，不能称已核实平台封面、SKU图或商品在售。实际只读样本返回6张图片，其中1张1000×1000公开图已下载、解码并查看；这不等于真实图搜验收。

## 产品、供应商与采购

有效新产品ID原子建立产品、需求关联和一次持久采购任务。同商家同产品可复用公共供货资料，客户数量、预算、地址、聊天、补充和私发图片继续独立。

产品可对应多个供应商及供货方案，可明确选择当前需求使用的有效方案；修改默认只影响以后新绑定的需求。选择及方案修订进入生成指纹，内部进价不是销售价，页面参考不能当供应商确认报价。

采购授权独立于自动接待，保存采购设置或重启会撤权。提交前持久确切请求，结果未知沿原任务核查，不因换客户、空链接或新job重搜。图片准备不占接待AI槽，采购AI仍与接待共用本商家执行槽。

**自动定向供应商询价和报价回收目前仍不可用，阶段明确blocked。** 真实图搜、全量SKU、长期采购调度和自动销售报价闭环尚未验收；不以Demo候选或页面价格冒充实际供应商回复。
