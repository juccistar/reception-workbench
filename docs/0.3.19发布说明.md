# 0.3.19版本说明

日期：2026-11-14。面向工作台使用者与维护人员。

状态：需求补录、自然分条回复和WhatsApp诊断已实现，正在完成最终联调、构建与隔离窗口验收。完成后按本轮明确授权直接打包上传；公开最新版当前仍为0.3.18。构建、候选、公开附件和下载结果以[验证记录](verification/0.3.19.json)为准。

## 需求补录与旧需求保护

AI会结合本轮可见的有效对话及已有事项目录，补建尚未记录的真实需求，或补入对应旧事项，不再只盯着最新一句话是否改变需求。最新一句只是感谢或普通闲聊时，有原文依据的补录仍可保存。

已经记录且没有变化时不重写整份需求。新采购、旧需求补充、更正和字段撤回继续使用增量契约；未提及的字段保持原值。修改同一规格字段中的颜色时，提示词要求保留仍有效的尺寸、材质等条件；已明确撤回的条件不能当作遗漏补回。

最近50条是聊天窗口，并非需求的有效期。已存需求与同会话事项目录独立进入上下文，有明确引用的窗口外本地原文继续补入。原文超窗不构成清空或重新归纳需求的理由。对于从未建档、原文已超窗且没有引用的旧需求，本轮仍可能不可见；本版没有增加全历史扫描。

商品段落严格只删除“平台商品ID及”，保留其余原文，没有增加关于ID选择、排除或判断的新提示。

## 自然分条回复

自动接待和普通人工建议由一次AI任务按语义生成1至3条消息，整轮正文合计最多1200字符。简单确认可以只有一条，不凑条数；价格、适用条件和必要限定保持在一起，避免拆开后产生误解。

分条会作为真实的独立平台消息逐条提交。每条有自己的发送操作、平台消息ID和回执，前一条确切受理后才提交下一条。整轮冻结正文、顺序和来源，并保持同会话互斥；中途出现客户消息、人工接管、暂停或依据变化时，停止未提交尾部。

unknown沿原操作核查，不换键或重发整轮。国际站明确未提交的暂时失败仍按同一条目的稳定归属，最多三次总尝试并按5秒、15秒退避；新任务或草稿不重置次数。WhatsApp不新增自动重发，继续要求确切消息ID和ACK≥1。重启后保留回执并停止未提交尾部。

## 人工建议与编辑

建议在输入框上方按条预览，采用后可分别编辑、删除或合并。分条润色只处理当前选中的冻结条目，其他条目保持原样；迟到结果不能按变化后的位置误替换。

普通手写继续支持单条直接发送，不增加AI、采购事项或买家最后发言等前置。人工正文预算继续为整轮50000字符。发送期间新增输入保存为新编辑版本，旧回执不能清掉新正文。

部分成功后，原草稿不能再次发送已受理前缀。界面提供“只保留未发送内容”，按原冻结批次核对并保留当前已保存尾部；已发送条目里存在新增编辑时保留全部正文，提示先移动新增内容，不静默丢字。界面显示逐条进度，并可核查原未决操作。

WhatsApp继续使用原始网页聊天区，工作台只增加批次进度，不创建第二套聊天列表。首条尚未提交时修改绑定，会保留原待回复消息供重新生成；已经部分提交或结果未知时不会因此重播整轮。

## WhatsApp诊断与有效页面保留

继续使用单个原始WebContentsView与同页面SDK。SDK初始化失败时退役程序接待、释放本代回调与CDP连接，已确认可信的原始页面可以继续显示。页面可用与自动接待就绪分别报告，HTTP、TLS、关闭或不可信导航仍单独视为页面故障。

连接过程记录固定阶段、错误分类和本地诊断编号。商家私有诊断日志最多2 MiB×3份，只保存版本、阶段、固定错误码、异常类型与程序内相对堆栈位置，不保存原始异常全文、聊天、账号、二维码或凭据。重连先清理旧绑定，旧回调不能控制新连接；HTTP 429继续遵守等待时间。

宿主状态直接通知界面，迟到查询不能覆盖刚收到的故障。故障撤销原自动接待授权，恢复连接不会自动恢复发送权限。

## 验证范围与使用边界

定向验证覆盖消息数组、需求增量、窗口外引用、原生来源防重、普通及补充续答、人工分条、重试、WhatsApp提前ACK/回显、取消与恢复。类型和静态提示词一致性检查通过。没有运行全量测试；最终通过数、实际窗口截图、候选与公开下载核对结果记录在验证文件中。

此前WhatsApp诊断基线已于f7f3c51构建并在71c3fb7保存验收：实际Demo窗口6图、正常冷启动及受控SDK故障后的公共扫码页2图均已查看，两组二维码观察均超过60秒并覆盖刷新。这些历史结果与本轮新增分条结果分别记录，不能互相替代。

所有业务回归使用临时Demo数据与合成结果。公共扫码脚本使用实际编译宿主和固定SDK，但在内存替换业务启动入口，并遮去二维码等媒体；它不能证明真实商家启动或实号收发。实际商家原连接故障尚未复现，真实AI表达质量、实号登录、重连及客户收发尚未验收。

本版不加入应用内旧数据清理；此前一次性本机维护没有重复执行。安装替换、默认入口晋级、真实数据迁移和私有源码推送不在本轮交付范围。
