# 0.3.12 商品字段、首查复用与接待界面清理

日期：2026-11-13。供接待业务员、维护和验收人员阅读。实际安装版本以窗口为准，公开交付及完整性校验状态见[验证记录](verification/0.3.12.json)和[发行页](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.12)。

## 商品随需求保存

采购需求新增正式product_ref：商品ID、产品链接、可用产品图片、参考标题、现有SKU及原文来源，和现有九项客户需求分开保存。客户页、客户资料及待报价读取同一份信息。可靠且适用于当前客户的商品引用可以满足待报价的产品条件，链接或图片缺失不阻断正常接待；数量、规格和收货地仍按当前必填配置判断。

支持实际收到的纯文本询盘格式：“This is a inquiry card. Inquiry id is ...; Product id is ...; Product Name is ...; The note of the buyer's inquiry is ...”。不要求平台先返回本地约定的JSON卡片。商品标题只作识别参考，标题里的Custom Logo不等于买家实际提出定制；事实核验和Logo重复提问提醒按买家留言区分。

同一商家、平台、商品ID的不同客户询盘关联同一商品档案，为后续报价复用商品资料打基础；客户自己的数量、规格、预算、聊天和业务补充继续独立。不把某客户“不适用”的判断变成所有客户都不能采用该商品。

## 首次受控查询与空结果

首次关联当前商品时，由程序通过正式只读get-product认领一次查询，再交给现有主接待AI；回复、摘要、需求和product_ref在同一主任务输出，没有新增独立链接解析模型。只针对当前回复来源或当前已关联商品，不扫描全部历史卡片。首次查询会增加工具等待，缓存后的任务不再重复该等待，不承诺首轮与纯文字同速。

查询前保存querying，后续保存completed、no_link、failed或unknown。换客户、新询盘、新AI任务、补充变化、空链接及重启都不重置记录；同时请求相同商品复用原任务。重启未完成的查询转unknown，不自动再查。需要新尝试时，明确点击“重新查询商品”，保留原记录；该操作只查商品，不生成或发送回复。

客户原文中的可靠公共商品链接可独立更新商品档案，供相同商品的其他客户复用；去除查询参数、校验商品ID和官方路径，不改写原工具no_link证据。来源原文改变会使旧关联失效，来源变化或任务取消不会推广旧链接。

**实际只读接口样本没有返回商品URL、主图或可验证的SKU图，因此本版不保证任意商品ID能获得链接。** 无链接会如实保存，不拼接URL，不轮换工具搜索补链。自有商品查询接口的归属拒绝已保留，没有绕过或作为fallback。真实商品卡/SKU采集仍未平台验收；已有可靠图片才保存，不强求补齐。

## 上下文与界面

商品链接、白名单商品字段及有限查询参考可进入上下文，明确reference_only、listing_details_verified=false及allow_product_lookup=false。国际站商品可能批量上货，页面价格、材质、规格、库存、交期、认证或定制能力不能直接当作商家已核实事实。普通正文润色保留冻结正文，不新增商品查询或需求写入副作用。

右栏保留摘要、客户需求及下方业务补充，彻底移除“整理与复核需求”表单；客户页、待报价和客户资料保持一致。建议预览保留正文、中文译文、采用及必要短状态，去掉内部协助长文、质量分析长文和应用规则版本名单。相关后台证据与兼容记录保留。

继续使用业务补充驱动逐问题跟进；身份、授权、来源校验、整会话prepared/sending/unknown保护、accepted证据和最多三次未提交暂时错误重试保持执行。

## 完整上下文与找货验证

[完整接待上下文](0.3.12接待完整上下文说明.md)附实际生成路径捕获的完整请求文件，包含全部指令及本轮模型JSON。隔离Demo中两个客户、三个生成任务共查一次商品，客户私有需求没有共享。另在授权Accio环境完成一次合成文字AI调用，正确返回商品ID和空URL，没有报价目录参考价或把标题定制确认为客户要求。

首次检查器误将合法ask动作判失败，原记录保留；对同一响应离线核对通过，没有重调模型。CLI未直接输出结果，使用既有的本请求completed-record恢复，传输异常和剩余质量提醒保留在记录中。该单一合成场景不替代真实客户长期接待或发送验收。

[后续自动找货路线](自动找货技术路线验证-0.3.12.md)已验证飞书技术任务触发Accio Agent原生只读搜索；外部直接CLI/MCP搜索API未验证，原生结果没有任务ID，数量也不构成严格MOQ过滤。本版没有加入采购工具箱、供应商管理/绑定、询价、报价核算或自动报价；没有向真实客户或供应商发送测试消息。
