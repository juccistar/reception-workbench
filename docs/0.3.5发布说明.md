# 0.3.5 发布说明

本版修复本机翻译网关配置无法保存的问题。[0.3.5已公开发布](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.5)并设为最新版本，四个附件的服务端SHA-256及匿名完整下载核对通过，详细范围见[验证记录](verification/0.3.5.json)。

## 修复内容

- 支持 Magpie 等本机 HTTP 翻译网关，包括 `http://127.0.0.1:3425/v1`、`http://localhost:3425/v1` 和 `http://[::1]:3425/v1`。远程服务继续使用 HTTPS。
- 同时修复桌面宿主和 Python 后台的地址校验，仍拒绝远程 HTTP、含凭据的 URL、伪装本机的域名和歧义 IP 写法，不跟随重定向。
- 设置页直接说明支持的地址，并显示固定的地址无效、取消及版本冲突提示；保存失败时保留输入，不回显密钥或任意后台异常。
- 聊天翻译范围、持久缓存、加密密钥和原有 Accio 需求分析、回复及发送流程沿用 0.3.4。

## Magpie 配置

在“连接与设置 → 聊天翻译设置”填写：

| 字段 | 值 |
| --- | --- |
| 服务地址 | `http://127.0.0.1:3425/v1` |
| 模型 | Magpie 列出的完整模型 ID，例如 `codex/gpt-5.6-luna` |
| API Key | 按 Magpie 本机网关说明填写，例如 `magpie` |

勾选启用并保存，再执行“合成检查”。真实模式检查会在确认后调用一次模型，可能计费。读取本机 `/v1/models` 已确认上述模型存在；本次没有执行 Magpie 的付费生成请求。
