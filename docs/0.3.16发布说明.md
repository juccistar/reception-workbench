## 需求与同客户多笔采购

自动接待和普通人工建议仅在确需建立或更新采购需求时返回 requirement_changes。没有变化时沿用已保存需求，更新只覆盖明确字段；空值不隐式清除旧要求，清空须有明确撤回或更正依据。数据库继续保存完整的 ai-v1 中文需求，商品链接仍由程序派生。

同一会话提供已有事项目录及必要旧依据，支持延续当前事项、切回旧事项、真实独立采购新建及同轮多项变更。原文归属不明时自然澄清，不猜测目标。重复来源或任务恢复复用原事项，不因换 job_id 再建需求。独立需求修订与普通任务、摘要更新分开；手动浏览旧事项不会因后台更新别的事项而被强行切走。

普通人工建议完成后可保存明确、有依据的需求变更；采用／弃用只处理建议正文，不等同于发送、接管或事实回滚。润色继续只处理冻结正文。与回复有关的各事项及供货版本纳入发送保护。

## 图片与产品链接

商品、需求、聊天及补充图片使用居中的原图预览，支持适配窗口、原始尺寸、遮罩关闭、Esc 和适用的组内切换。原图按需从本地缓存分块读取，普通快照继续只携带受限缩略图，不提高全局协议预算。

缩略卡及大图右键提供“复制图片”，使用对应原图的全尺寸像素。为兼容 Windows 剪贴板，复制时生成应用 EXIF 方向、保留透明度的全尺寸 PNG；不改写源文件，也不承诺保留原文件编码或元数据字节。原图、归属或版本不可用时明确失败，不回退成低清图片。

产品链接完整展示，可换行；点击文字复制，独立箭头经受限宿主入口在系统默认浏览器打开。定制编号不生成平台链接。

## 接待交互

历史图标一次点击直接发起当前客户的历史补全，执行中防重复，不再打开解释卡片。当前客户的恢复／暂停自动接待按钮移到顶部，仍受原有发送、保存、全局状态及授权检查约束。

状态和附件限制等临时信息弹层支持点外、Esc、再次点击关闭与同级互斥。待处理建议仍按替换／弃用流程关闭。补充内容独立滚动，“＋”“？”和保存状态固定在面板底部。删除客户名称前的字母头像，摘要书本图标保留。
