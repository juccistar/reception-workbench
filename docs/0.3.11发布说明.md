# 0.3.11 需求展示与业务补充跟进

日期：2026-11-12。供接待业务员、维护及验收人员阅读。实际安装版本以程序窗口为准，公开交付及校验状态以[验证记录](verification/0.3.11.json)和[发行页](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.11)为准。

## 本版变化

右侧采购需求只保留“摘要”和“客户需求”，下方继续保存业务补充。内部规则、本轮变化、商家条件、回复依据、事项历史和飞书版本不再堆叠显示；原文、候选、整理和修正按需展开。多事项、窄窗抽屉和独立保存的聊天正文继续可用。

取消常驻协助表单。业务员直接聊天或填写最新业务补充，正常自动接待或人工建议任务结合当前消息逐问题判断：待回复、待你补充、待客户回复、暂无待办、状态待更新。不要求逐项点击开始处理；人工接管、未读、采购进度和发送回执仍分别记录。

补充可以提供当前客户的报价、运费、库存或沟通安排，不写成客户预算或已同意。保存先使旧来源待更新；自动接待已授权且问题仍有效时，复用主业务任务生成补充续答。只回答价格不会关闭运费问题，生成正文不等于已经发送；相应草稿取得平台受理回执后才记录该问题已回复。暂停、人工接管或 AI 不可用时保留补充和待更新状态，不恢复权限或新增独立分类调用。

同问题使用稳定身份累计重试，修改补充不重置最多三次及5秒/15秒退避。不同问题可分别跟进。整会话 prepared/sending/unknown 保护、原操作核查、本机受理证据及正常自动发送的全部业务检查继续执行。

## 图片和商品链接

需求区可展示客户参考图、商品链接及可识别结构化商品卡中已有的主图/SKU图；展示缓存按商家保存，封面重开保留。图片使用本地安全预览，商品图后台有界加载不阻塞回复，也不改变生成指纹。

展示资料与模型输入分开。普通客户展示图、商品链接、商品卡 JSON 和 SKU 元数据不额外进入模型；只有当前事项关联的产品来源图片，或无竞争来源的新采购单张买家图候选，才可进入相关任务。商家图须有买家明确引用，设置封面不授予读图资格。产品值仍为文字，视觉候选不能冒充买家原话或确认属性。普通润色不准备历史图片。

正式只读商品接口样本只有商品说明及部分文本属性，没有主图、SKU实体或SKU图；匿名公开页返回登录页面。当前已完成的是本地卡片图片解析、受控下载及缓存展示；`cardType=product`、`skus/imageUrl`这套结构来自解析器约定及合成测试，尚未取得真实商品卡或询盘卡样本证明平台会按此格式返回。正式消息接口声明的content为字符串，cardInfo内部结构也未声明，真实SKU采集链路尚未完成平台验收。**不保证真实询盘能提取SKU图，也不保证任意商品链接自动补齐主图或全部SKU图片**。缺失时明确提示，后台不执行登录脚本或绕过登录。结构样本不能用作本商家的经营事实。

当前仍使用同任务 read_compat；没有新增原生图片附件接口。只有本轮确切原生读取证据才算已看图，准备和预览不等于模型读取。保留2秒检测、1秒合并、50条文字及窗口外必要依据，已有明确配置继续使用。

## 验证和交付边界

已完成并公开发布：322项后端、133项桌面及宿主定向用例通过，类型检查和最终打包构建通过；最终EXE的11张截图逐张查看，两个运行目录正常关闭及重开。安装包、便携ZIP、blockmap和latest.yml的服务端摘要与匿名完整下载均和本地文件一致；公开版本为latest正式版。实际 Electron 源码窗口及最终包窗口分别留证。图片展示和状态截图使用本地合成数据，逐问题续答与发送保护使用替身和临时数据库。测试与截图不能代替真实平台长期运行、真实客户发送或真实模型语义质量验收；本版没有据此宣称时延改善百分比。

打包使用固定 Ed25519 公钥核验更新元数据，Windows Authenticode 状态另行记录；最终安装目录、便携包、冻结源码和公开附件按实际结果核对。打包上传不替换本机已安装程序、不迁移业务数据、不恢复自动接待授权。完整备份仍须保全业务库、图片、发送账本、原回执及有效 WAL。

实施方案见[需求展示与自动跟进状态](需求展示与自动跟进状态开发方案.md)，操作见[用户指南](USER_GUIDE.md)和[连续接待](自动接待连续性.md)，提示词见[审核稿](接待提示词审核稿.md)。历史0.3.10的真实合成AI及多图证据只证明当时版本，不代替本版图片边界或补充续答验收。
