# 0.3.8 本地候选说明

本版合并自动发送通道简化和卖家图片修复。本地安装包和便携候选已构建并核验，最终 EXE 的两轮隔离 Demo 窗口检查通过。尚未上传或公开发布，也未替换本机安装。实际结果见[候选验证记录](verification/0.3.8.json)。

## 本版内容

- 常规自动回复保留完整业务检查，直接使用聊天提交通道，移除发送前的整段平台历史重读、账号级 Ready 快照、历史卡片逐条比对和 Seal 封装。简短确认、正式续答和协助跟进也使用本地来源及已受理凭据校验，不再发送前重读平台历史。
- 保留当前身份、客户归属、本轮检查和授权、客户范围、授权起点、人工接管、停止联系、本地来源与正文/需求/资料/业务补充/图片版本，以及防重和失败重试规则。正常消息同步继续运行，尚未同步到本地的新平台消息可能稍后才被发现。
- 提交前保存未决提交记录，提交后保留确切的平台消息编号并有限读取确认；回执最终保存临时失败也保留已返回编号。旧快照未知操作继续核查原回执，不改通道重发，不补发历史失败消息。
- 商家图片支持自动加载、缩略图、放大、重试和缓存重开。按图片实际发送方核实原图，仍限定当前商家、客户、会话、消息及版本。
- 自动接待、人工建议和润色均可使用买卖双方原图。每轮双方合计最多四张，引用及模型清单明确携带 role，区分买家参考图和商家展示图；图片不直接作为买家确认事实或卖家承诺，不恢复独立图片识别任务链。

详细实现见[发送通道简化](自动发送通道简化.md)和[卖家图片与上下文](卖家图片与上下文.md)。

## 验证及使用边界

发送通道改造已通过 202 项相关定向用例；图片修复已通过 78 项后端、9 项界面相关定向用例、类型检查及构建。两组后端用例存在重叠，不能直接相加。源码的隔离 Electron 窗口已验证双方图片、卖家图放大、模型上下文角色和缓存重开，截图已实际查看。包内程序版本 0.3.8、冻结源码及构建输入匹配、163 文件发行清单、ZIP 完整性和固定 Ed25519 更新签名均已核验。最终 EXE 实际验证了卖家图预览/放大、双方图片上下文、缓存重开，以及原有翻译配置、译文缓存、本机 HTTP 网关和重启暂停；截图已实际查看，两轮窗口均正常关闭。

没有运行全量测试，未调用真实付费模型、发送真实客户消息或访问生产数据。真实 Accio 直接自动发送及卖家原图读取尚未在本轮商家环境验收，Demo 不替代真实平台验收。安装包实际安装也未执行。

数据库 schema 仍为 v2，适配器 Ledger 仍为 v1。已有账本、消息、回执及有效 WAL 保留，不迁移业务数据，不晋级默认入口，不自动恢复接待权限。升级前保存编辑并正常退出，按现有流程完成完整备份；更新后从对应商家的 Accio 授权环境启动。

更新元数据使用既有固定 Ed25519 密钥签名；没有 Windows Authenticode 代码签名。本地候选的构建、公开发布、安装及真实业务验收分别记录。
