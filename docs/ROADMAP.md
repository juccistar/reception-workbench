# 后续维护与待验证事项

当前项目为独立私有仓库`juccistar/reception-workbench`，默认分支为`main`；发行仓库继续使用`juccistar/reception-workbench-releases`，见[项目约定](PROJECT.md)。新目录的独立依赖、108项后端定向检查、87项工具测试、类型、构建及实际Demo窗口检查已通过；0.3.3已公开发布并核对四个附件的服务端摘要与匿名下载。来源、验证和发布记录见[清单](SOURCE_BASELINE.json)、[验收](verification/0.3.3.json)及[版本说明](0.3.3发布说明.md)。这些结果不代替下面的真实平台验收。

- 核实原故障中14字符Ready展示的实际格式及其是否符合窄兼容条件。未知展示、普通文字及当前来源差异仍严格拒绝，不凭长度或语言猜测等价。
- 在目标商家和明确对象授权下，观察真实新买家入站、连续两轮生成与原生发送回执，验证本补丁在实际平台的效果。不能伪造入站或补发旧unknown来制造通过。
- 继续真实双Accio并行接待、整班稳定性、正式NSIS跨版本安装与重启、干净机器重建及语言质量验收。真实AI、平台发送与飞书写分别按授权及证据核验。
- 按实际业务反馈完善采购需求复核与报价交接，保持自动接待与普通人工聊天两条路径，不把内部补充当成客户已确认事实。
- 清理旧目录前，单独完成真实业务数据和恢复集合的保全及迁移核验，见[迁移说明](MIGRATION.md)。源码复制不证明数据已迁走。
