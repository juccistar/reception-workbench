# 自动接待启动与授权

本文维护日常启动、检查和授权流程；实际安装版本以程序窗口为准。

工作台以自动接待为主，客户页始终可直接手写聊天。人工发送不需要先检查AI，也不需要切换独立人工模式；详见[人工聊天](人工接待使用.md)。

## 1. 从目标商家授权环境启动

可在演示页面或“服务未连接”页面顶部点击“复制 Accio 启动指令”。指令调用当前EXE的`--connect-from-accio`，不绑定seller、数据根或workctl；复制不会执行命令或关闭窗口。程序先使用当前授权Native的resolve-id识别真实商家，再按registry选择独立profile，后台连接时再次核验身份。无后台快照时也可点击“查看连接诊断”，读取本机数据目录与受控错误，不调用平台或AI。

重连同一商家前先保存编辑并正常退出该商家的旧窗口，再将指令粘贴到允许启动此工作台的目标商家Accio Work授权会话中执行。不同商家可保留各自窗口，同一商家跨数据目录全局排他；Native子进程继承占用，父进程异常退出但子进程仍存活时也拒绝第二个owner。启动继承当前会话授权环境；如果该环境拒绝启动或不允许外部程序使用授权，停止并核实支持的接入方式，不换渠道代执行或复制令牌。真实双Accio并行接待闭环仍待验收。也可以使用程序“帮助 → 复制 Accio 启动指令”；若从本工程目录启动，则执行：

```powershell
& '.\授权启动接待.cmd'
```

需要固定预期卖家时可增加`--expect-seller`及真实数字AliID；不要把Accio账号目录编号当卖家ID。通过当前宿主提供的工具路径继承授权，不复制令牌、不扫描其他账号；已有窗口不能通过重复启动命令注入新授权。普通双击默认演示。

新窗口只核验身份和读取，不自动调用AI或发送。先核对卖家尾号、当前实际数据目录和客户归属，不按历史截图判断当前检查状态。

## 2. 检查自动回复能力

在连接与设置点击“暂停并检查 AI”，按系统确认执行一次合成检测。它会消耗一次AI调用，不使用客户正文，不发送消息或写飞书；失败时看原任务及安全诊断，不盲目重复调用。

已有具体AI草稿时，可另做发送预演。预演是该草稿的诊断，**不是开启全局自动接待的前置**；每条真正自动发送仍重新执行原生预检及最终权限检查。

## 3. 选择本轮范围

| 范围 | 行为 |
| --- | --- |
| 仅选定客户 | 只处理本轮明确选中的客户 |
| 开启时已同步客户 | 冻结开启时名单，不自动纳入后来客户 |
| 授权后新消息 | 按起点处理新买家消息，包括后来出现的新客户；历史不自动补答 |

根据实际业务保存本轮范围，再明确授权并核对系统确认框。0.2.22起不设置AI和自动发送次数上限；图片识别、文字生成及其重试继续分别记录调用，自动发送也继续统计。旧版显示数字限额时以实际运行版本为准。

保存范围不会自动开启接待。需要发送测试消息时，按当前明确授权的对象和范围执行。

暂停后统计不清零，配置变更仍撤销授权，重启不恢复旧授权。人工编辑只暂停当前客户，恢复该客户需明确操作且全局授权有效。取消次数限制不会改变消息读取节流、上下文大小或图片资源限制。

## 4. 观察接待结果

自动接待先回答客户眼前问题，再逐步补齐采购条件。寒暄不强制问卷；费用、库存或交期待核实时说明后续核实并形成协助事项。0.2.22的商业承诺及数字依据校验只作质量提醒，不因提醒暂停回复；无效事实仍不能确认。待你协助不等于人工接管，回填核实结果后可按当前授权继续跟进。条件齐全进入待报价后仍可沟通，普通聊天不清掉旧事项。

新入站验收应有真实买家消息，依次观察同步、需求/上下文、生成、原生受理回执及事项状态。卖家自己发出的消息不能冒充买家入站，演示消息也不能算平台闭环；没有新入站时保留待验收状态。

0.2.15修复了同一历史图片在快照中`[Card]`、平台中`[image]`的表示差异。新核验失败可在运行记录查看“快照核验差异”；旧失败记录原样保留，不会因升级自动补发。

## 5. 异常、退出和数据

生成超时或格式错误时，程序自动整理或保留任务退避重试，不要求每次点击重新生成。通道可用且授权有效时，可先发送一次简短确认，再继续最终答复；同步延迟继续后台核查，不把排队显示成已回复。具体状态见[连续接待说明](自动接待连续性.md)。

发送中等待原请求；unknown保护整个会话，按原操作核查，不换正文、事项或编号试发。任务入队和预演通过不等于平台已受理。

退出先保存编辑，程序撤权并等待在途结果落库。备份、迁移和恢复优先使用设置页完整数据入口；操作对象以页面显示的实际目录为准。飞书可选，不阻断本地接待。

具体业务操作见[用户指南](USER_GUIDE.md)，当前规则见[现行规则](CURRENT_RULES.md)。
