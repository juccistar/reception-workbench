# 自动接待连续性

供接待业务员和维护人员使用，介绍当前连续接待及发送重试规则；实际版本以程序窗口核对。

## 开启接待

仍从当前商家已授权的Accio Work环境启动，核对商家及数据目录，完成当前连接的读取与合成AI检查，保存接待范围后明确开启。详细步骤见[启动与授权](自动接待启动与授权.md)。

AI调用和自动发送不再设置次数上限，界面继续显示实际统计。接待AI统计包含客户文字生成、图片识别、重试和明确请求的手动生成；合成能力检查单独保留任务记录。暂停不清零统计；保存范围或普通设置仍撤销当前授权，重启仍保持暂停。无需选择新的接待模式。

## 四类状态怎样处理

| 页面状态 | 含义 | 操作及后续 |
| --- | --- | --- |
| 质量提醒 | 正文中的商业条件、数字或表达可能缺少依据 | 可用正文仍可继续处理；查看提醒并补充可靠资料或核实结果 |
| 待你协助 | 某个问题需要业务员核实，或采购事实有冲突 | AI继续接待，业务员可回填核实结果；不必接管整个客户 |
| 自动重试中 | 生成超时、格式不完整或通道暂时不可用 | 程序保留任务并退避重试，通常无需反复点重新生成；有新消息时按最新内容重新规划 |
| 人工接管 | 业务员已明确接管或开始实际手写编辑 | 该客户的自动处理暂停；需要继续自动接待时明确恢复此客户 |

同一客户可以同时有协助待办和人工接管。查看客户、展开或复制建议、打开设置、查看依据不会因为这些查看动作接管客户。采用建议到输入框属于人工编辑，会接管该客户。

## 核实结果怎样返回客户

在客户页或待报价事项展开协助区域，滚动查看各项问题，核实后填写结果。客户页为聊天记录保留显示空间，协助区内容较多时可独立滚动，未实际显示的聊天消息不会因展开表单而被标记已读。选择仅供内部使用时，结果保留给业务员，不会进入AI对客上下文，也不会安排对客跟进。

允许用于回复客户的核实结果，会进入本客户、本采购事项的AI上下文；勾选“安排自动跟进”后，程序按填写的确切正文安排发送，不另行调用AI改写，请使用适合客户阅读的表述。提交前仍核对当前消息、来源和接待授权。若已暂停、该客户已被人工接管或连接尚未恢复，会保留等待状态；填写结果本身不会开启接待或抢回客户。

“已保存核实结果”“已安排跟进”“正在生成”和“平台已受理”是不同阶段。只有取得权威发送结果后，才显示跟进已回复；发送未知时继续核查原操作。

AI在回复中表示需要核实库存、价格、交期等信息时，应形成对应协助待办。不要仅凭一条质量提醒就把真实库存或报价填写为确认资料；核实结果和经营资料应由业务员提供。

## 正文和采购事实分别处理

商业承诺或正文数字缺少资料依据，会记录质量提醒，继续接待。提醒不会被当作已经核实的承诺。采购事实仍逐项核对买家原文：无效提取不能成为确认字段，冲突保留依据并等待澄清，合法正文可以继续回复。

事实齐全进入“待我报价”后，AI仍可回答新增问题、记录规格数量地址或照片。新采购建立独立事项，原待报价事项继续保留。单纯致谢或告别可以等待下一条消息，避免循环追发。

## 生成和同步暂时失败

完整但外包代码围栏、缺少可确定补齐的结构字段等格式问题，可直接整理修复；修复不能猜造事实或把原始工具载荷当正文。无法得到完整可用正文时，保留原任务并自动重试。

临时超时或通道故障按退避间隔恢复，运行记录显示尝试与结果；一个客户失败不应使其他客户退出接待。需要等待较长生成时，通道可用且当前授权有效的情况下，可先发送一次简短确认，再保留最终答复任务。简短确认不是最终答复，不应导致后续答复被永久取消。

新消息到达后，旧来源建议和重试会失效，程序以最新消息合并规划。已经保存的人工正文不会被新建议覆盖。无法可靠取得的图片保持未观察状态，文字接待仍可继续，不声称已经看懂。

## 0.3.1的自动发送重试

正常AI调用和自动发送总量不限，统计继续保留。针对同一商家、会话、来源消息及回复阶段的一条自动发送失败链，最多三次自动尝试（首次加两次）；协助跟进还按结果版本区分。只有明确属于暂时性故障且已确认提交尚未开始时，才分别在5秒、15秒后重试。确定性或未分类拒绝停止本条重试，保留安全原因；新任务、新草稿或重启不重置计数，历史已超限也不再重试。此规则覆盖普通自动回复及确认、最终答复和协助跟进，不改变其他客户授权；真正的新入站仍按当前权限处理。

可能已提交或结果unknown时仅核查原操作，不能以重试次数为由另发。生成失败的恢复与发送失败链限次是不同环节；上文生成重试说明不代表发送可无限重试。

## 仍需等待的情况

身份或客户归属无法核验、客户明确要求停止联系、人工接管、当前范围不允许、全局暂停，以及原消息可能已提交但结果未知时，仍不能自动提交新的消息。这些状态会保留原因和任务，不能把它们显示成“已回复”。

结果未知只核查原操作，不换请求编号、事项或正文重新发送。网络或平台不可用期间无法保证实际送达，但程序应显示等待与恢复状态。数据迁移、备份、恢复及退出行为沿用[用户指南](USER_GUIDE.md)与[数据说明](DATA_AND_RUNTIME.md)。

## 资料准备

经营资料页提供产品、样品与Logo、交期、运输和售后等模板。模板用于提示应填写什么，初始不含真实价格、库存或交付承诺，需业务员补充内容、适用产品/条件、确认和公开状态及有效期。

提示词继续要求自然回答当前问题、使用可靠事实、未知事项核实后跟进；质量问题与后续修订保留记录。自动恢复次数和界面演示不等于真实模型质量或真实平台持续运行已验收，两类证据分别记录。
