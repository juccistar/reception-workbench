# 0.4.1 发布说明

面向工作台使用者与维护人员。本轮已实现追加的统一账号首页、多账号独立运行、完整授权口令复制与 Chrome 客户侧栏，正在完成窗口联调和新候选B打包。候选A仅保留为旧范围基线，新候选与实际核验结果以[验证记录](verification/0.4.1.json)为准。

## 主要变化

- 启动台使用“全部 / 国际站 / WhatsApp”三个分类，两种账号在同一列表并列。每张卡片直接连接或打开窗口，编辑按钮紧邻状态；设置在右侧面板打开，窄窗口使用全宽面板和固定保存底栏。
- 多个不同 WhatsApp 账号可同时连接和运行。各账号分别使用专用 Chrome 窗口、后台、客户绑定及发送账本，断开或故障只影响相应账号；托盘也按账号提供操作。同一真实账号继续受原环境和账本所有权约束。
- 新增可收起的 Chrome 原生客户侧栏，跟随当前单聊展示客户、接待商家、摘要和需求，支持搜索关联国际站客户、人工接管与恢复。搜索只读取相应商家已保存的客户名称和买家标识，不要求手填会话ID。原网页继续用于人工聊天。
- 国际站授权弹窗提供“复制口令”，复制宿主生成的完整三段说明及命令，安装路径随当前版本生成。国际站显示名称是本地备注，已核验公司身份独立保留。
- 连接失败短因显示在原状态位置。只有结果未知的发送操作才显示“待核查”，核查沿用原操作，不提供重发，也不增加逐条发送审批。
- 全部国际站、WhatsApp账号及模型能力检查共用当前Windows用户的模型额度：接待1槽、翻译1槽、HTTP合计2、带图最多1。等待队列有界，取消后实际清理完成才归还额度。
- 全局多API配置继续分别选择接待和翻译用途，使用真实Windows用户共享目录和CurrentUser DPAPI；Chrome网页和扩展不接收模型Key、Accio令牌或通用业务接口。
- 消息中的有效需求图片、Logo和定制依据，以及无事项时可明确选择的买家图，均可与文字同轮提交原图。清单来源、原图字节及已审核附件提示词保持一致，历史补读和重复引用按确切来源去重。
- 固定system提示词保持原样，user按资料、接待指引、风格及嵌套context组装；客户上下文依次放置补充、摘要、需求/供货、聊天及本轮目标。保留原内容、数组顺序、角色、预算与本地语义指纹，未测量真实API缓存命中率。
- 透明白色PNG使用明暗棋盘底，透明预览保留Alpha；旧预览可从已校验本地原图只读恢复。商品图在原超时内尝试后续已校验CDN地址，保留证书、图片和来源身份检查。
- 授权启动入口兼容当前Accio工具目录布局。离线备份恢复继续保全消息、媒体、绑定、账本和unknown，恢复后自动接待关闭；Chrome登录profile不进入业务备份。

## 使用边界

首次使用新的Chrome环境需要扫码，程序不复制旧Electron Cookie。商家背景需由对应已核验商家窗口在线提供；更改联系人商家后暂停该客户接待，新联系人默认商家不会覆盖明确未分配的旧客户。

当前聊天识别在账号、连接代次、运行实例及聊天ID变化时清空旧资料。集合不可用、群聊、频道或无法确定当前单聊时，侧栏保留空状态；旧读取和操作结果不得带到新客户。客户搜索最多返回25条元数据，仓储没有可信买家公司字段时不会补造公司。

WhatsApp反写国际站接口仍关闭；自动定向询价和报价回收继续按既有路线图记录。
