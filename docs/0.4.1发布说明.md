# 0.4.1 发布说明

面向工作台使用者与维护人员。候选A已于2026-11-16构建，产品源码为c585aee，构建后立即本地提交71b478c。包与窗口核验已完成，最新公共扫码两组通过，但此前间歇性初始化超时的根因仍待确认；当前GitHub CLI未登录，尚未上传、公开发布或安装。实际状态以[验证记录](verification/0.4.1.json)和公开发行仓库为准。

0.4.1将WhatsApp移到启动台管理的真实Google Chrome窗口，并修复聊天原图遗漏、透明白色PNG显示和启动台公司名称。包含0.4.0尚未公开的启动台、多API及接待/翻译用途统一配置。

## 主要变化

- 启动台商家主标题显示已核验的公司名称，保留账号尾号；支持发现旧登记和导入明确的登记目录。共享模型与账号环境定位到真实Windows用户目录，避免Accio环境变量重定向产生空配置。
- WhatsApp使用系统安装的Google Chrome和专用profile，从启动台创建、连接及定位；商家窗口的旧内嵌入口及视图专用实现退役。无国际站商家也可扫码和人工聊天。
- 一个WhatsApp账号可按单聊绑定不同商家，也可设置新联系人的默认商家。资料由在线、已核验的商家工作台只读提供；切换绑定形成新接待段并默认暂停，旧未决发送继续保留原操作核查。
- 修复消息图片误限于已有事项商品图来源的问题。当前需求中的Logo、定制等有效图片依据与无事项时的唯一买家图可进入本轮请求；原图、来源清单与审核过的原生附件提示词一起提交。历史补读及重复引用按确切来源去重。
- 调整模型JSON字段顺序，使任务元信息、低频配置和适用资料形成较稳定前缀，已有聊天先于本轮目标与滚动摘要。此调整保留原字段、正文、数组顺序、角色、预算和语义指纹；未测量实际API缓存命中率。
- 透明预览保留Alpha，聊天和原图使用明暗棋盘底；旧白底预览可从已校验本地原图恢复显示，原图与数据库缓存不改写。
- 商品图在原超时内尝试后续已校验CDN地址，保留证书与网络校验；商品身份变化后丢弃旧采集结果，透明展示图保留透明度。界面沿用已有简单提示。
- 新增账号离线备份恢复入口，保全消息、媒体、绑定、发送账本及旧来源归档。恢复至空目标，unknown继续保留，自动接待保持关闭；Chrome登录profile与商家当前资料不在账号备份内。

## 使用与核验范围

初次使用新Chrome环境需重新扫码，不复制旧Electron Cookie。商家资料接待需要对应商家工作台在线；Chrome人工聊天独立可用。一个Windows用户同时连接一个受管账号环境，保存多个环境后可切换。请先正常退出旧版本的WhatsApp自动接待，再核查旧接入记录。

相关后端138项、桌面/宿主15文件92项及工具2项定向验证通过，类型和提示词审核稿一致性检查通过。候选冻结后台完成两协议18次本地替身请求、14份图片附件，以及合成账号的离线备份恢复；恢复后unknown保留、自动接待关闭。未运行全量测试。
