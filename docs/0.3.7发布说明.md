# 0.3.7 发布说明

本版让业务补充参与自动接待，支持润色当前未发送回复及建议中文翻译，并调整图片上下文、公司名和工作台布局。[0.3.7 已公开发布并设为最新版本](https://github.com/juccistar/reception-workbench-releases/releases/tag/v0.3.7)，四附件的服务端摘要及匿名完整下载均已核验，实际范围见[验证记录](verification/0.3.7.json)。

## 本版变化

- 图片在主业务任务中直接读取：Accio 在本轮任务内读取指定原图并输出需求和回复，不再先生成独立图片识别报告再交给文字分析。每轮最多使用四张相关买家图片，原图复用本地缓存，只有确切的本轮读取记录才能作为已看图的依据。图片中的内容仍需结合客户文字判断，不能直接当作客户已确认的采购条件。
- 业务补充默认进入当前客户的自动接待、回复建议和润色上下文，不需要额外勾选。补充只保留当前最新文本，修改覆盖、清空移除，切换客户或重启后恢复当前值；保存补充不接管客户。更新补充会使尚未提交、依赖旧补充的 AI 回复失效，已经提交的发送继续沿原回执处理。
- 输入框留空时可“生成回复建议”，有文字时改为“润色当前回复”。润色使用点击时的未发送正文及版本，并要求保留价格、数量、单位、币种和承诺条件。结果先展示为建议，点击采用后才替换输入框；生成期间继续编辑的内容不会被迟到结果覆盖。
- 人工生成和润色后的建议加入自动中文翻译，沿用现有开关、第三方服务配置、队列及持久缓存。设置页和启用确认说明包含这一范围。译文只用于对照，采用和发送继续使用原文。
- 自动接待仍按当前授权直接发送。内部草稿用于绑定正文及来源版本，不增加等待人工采用的建议区；发送后的卖方消息沿用聊天翻译。
- 左下卡片只显示当前卖家的公司名，读取失败时可重试。窗口标题保留原有商家展示。
- 可拖动右侧栏的左右分隔线调整宽度，也可拖动需求和业务补充之间的上下分隔线调整比例；支持键盘和双击恢复默认，按商家保存，重启后恢复。

每次 Accio 业务调用仍创建独立请求，根据本地已有消息、需求、资料和当前补充组装上下文；本版没有新增客户长期记忆或远端会话续接。

## 升级与数据

保存编辑内容、正常退出工作台并完成完整备份后升级；真实连接仍从对应商家的 Accio 授权环境启动。重启后自动接待权限不会恢复，须按现有流程重新检查和授权。第三方翻译继续使用 0.3.6 的同电脑、同 Windows 用户共享连接，启用、聊天、译文和用量仍按商家及实际数据根分别保存。

数据库物理 schema 仍为 v2，适配器 Ledger 仍为 v1。启动时只定向整理旧业务补充的专用修订及幂等正文副本，保留当前补充和版本信息，不删除消息、发送 operation、outbox 或回执。历史回复和发送证据仍保留，不能将这些记录作为旧备注缓存清理。完整备份和恢复仍须整体保全业务库、控制库、适配器账本、回执及有效 WAL。

## 验证范围

100 项后端相关定向测试和 113 项桌面/宿主相关定向测试通过，类型检查及构建通过；没有运行全量测试。

源码和最终 EXE 均使用隔离 Demo 实际验证了：当前正文润色及中文对照、采用和发送保持原文、图片进入主业务请求且没有独立观察调用、补充覆盖及清空、拖动分隔线、关闭重开后的补充/正文/译文缓存/布局恢复，以及重启保持暂停。原有翻译配置加密、缓存及本机 HTTP 网关保存和重开检查也通过，截图已实际查看。最终包与源码、构建暂存输入一致，严格文件清单、ZIP 完整性及固定 Ed25519 更新签名核验通过；发布结果见验证记录。

上述检查使用临时 Demo 数据根、独立共享配置和合成原生记录，没有调用真实付费模型、向真实客户发送消息或访问生产数据。真实 Accio 图文能力和公司资料读取未在本轮商家环境实际验收；原生主任务内部是否使用视觉服务由 Accio 决定，本版不保证一次物理模型调用。最终 EXE 的隔离验收不能替代真实平台验收。

本轮不替换本机安装、不迁移业务数据、不晋级默认入口。安装包尚未执行安装验收。更新元数据使用固定 Ed25519 发布签名，不包含 Windows Authenticode 代码签名。
